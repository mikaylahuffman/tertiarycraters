# tertiarycraters
This repository includes code and data related to Huffman & Singer's tertiary cratering project. Here you will find code that calculates predicted boulder sizes using the Schmidt Holsapple Housen scaling relations and the remaining time before tertiary craters will degrade on the Moon's surface. Also included are various NACs, shapefiles, and spreadsheets of data relating to tertiary craters. Please reach out to mikaylarhuffman@gmail.com or mikayla.huffman@colorado.edu with questions. 

Code:

In the [Age Dating] folder, the [tertiary_crater_lifetimes_MRH_v2 python file] is the main code for determining how long the tertiary craters around Secondary A will persist on the lunar surface. In the [Scaling Relations] folder, the [shhcalcs+plot python file] calculates many characteristics of the tertiary craters around Secondary A.
